# 割喉冒險隊 Online

靈感來自桌遊《Cutthroat Caverns》的多人連線網頁版。純靜態網頁，可直接放上 GitHub Pages；手機、電腦都能玩，不用安裝任何東西。

## 連線方式
- 使用 [PeerJS](https://peerjs.com/)（WebRTC 點對點）：**房主的瀏覽器就是遊戲主機**，其他玩家直接連到房主。
- 不需要伺服器，也不用開 port。
- 房主重新整理頁面會自動恢復遊戲（狀態存在房主瀏覽器的 localStorage）；玩家斷線或手機休眠回來會自動重連。
- 房主請盡量用電腦，或保持手機螢幕亮著、不要切到別的 App——房主的分頁進入背景時遊戲會變慢或暫停。

## 上架到 GitHub Pages
1. 在 GitHub 建一個新的公開 repo（例如 `cutt`）。
2. 把 `index.html`、`game.js`（和這份 README）上傳到 repo 根目錄。
3. repo 的 **Settings → Pages** → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)` → Save。
4. 約一分鐘後網址會是 `https://<你的帳號>.github.io/cutt/`，把這個網址傳給朋友即可。

## 本機測試
任何靜態伺服器都可以，例如：
```
python -m http.server 8000
```
然後開 http://localhost:8000 。可以開兩個分頁分別當房主和玩家。

## 單人模式 / 電腦玩家
- 首頁按「🤖 單人遊戲」即可和 3 個電腦對手玩（大廳可增減，最多 5 個），不需要網路連線。
- 連線房間的房主也可以在大廳「加入電腦玩家」補人。
- 電腦只看自己的手牌和公開資訊：會搶殺、格擋別人的致命一擊、把怪物推給威望領先者、對領先者下詛咒。

## 玩法
1. 一人「建立房間」，把房間代碼或邀請連結給朋友（2–6 人，建議 3 人以上）。
2. 每回合隨機發先攻 → 每人秘密選一張**行動卡**（攻擊／包紮／防禦姿態）→ 全部翻開，依先攻順序結算 → 怪物攻擊。
3. 每次攻擊結算前有 10 秒**反應時間**，任何人都可打出**事件卡**（格擋、擦傷、狂怒祝福、誤傷友軍、推人擋刀、詛咒…），有人出牌就重新計時。
4. 只有**給予致命一擊**的人拿到怪物的威望。每場戰鬥後存活者回 10 HP、抽 1 張事件卡。
5. 共 8 場遭遇（最後是遠古紅龍）。HP 歸零就淘汰；最後**存活且威望最高**的人獲勝。

## 檔案
- `index.html` — 介面與 PeerJS 連線
- `game.js` — 遊戲規則引擎（卡牌／怪物資料在最上方，可自行調整平衡）
- `node-server/` — 舊版（自架 Node.js 伺服器），不需要可以刪掉
